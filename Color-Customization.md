# General format
You can use your own color preference
```yaml
color:
  textColor: <value>
  secondaryTextColor: <value>
  backgroundColor: <value>
  secondaryBackgroundColor: <value> 
  primaryColor: <value>
  secondaryColor: <value>

  darkmode:
    textColor: <value>
    secondaryTextColor: <value>
    backgroundColor: <value>
    secondaryBackgroundColor: <value>
    primaryColor: <value>
    secondaryColor: <value>
```
